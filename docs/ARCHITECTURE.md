# 系统架构

## 组件关系

```text
浏览器
  │ HTTP / SSE
  ▼
Nginx + Vue 3
  │ /api/v1
  ▼
FastAPI ── LangGraph StateGraph
  │          ├─ 图片质量工具
  │          ├─ YOLO26 视觉工具
  │          ├─ Qdrant RAG 工具
  │          ├─ 风险研判 / LLM
  │          └─ 报告与人工复核
  ├─ MySQL（任务、证据、轨迹、报告）
  ├─ Qdrant（知识片段向量）
  └─ 文件存储（原图、结果图、知识文件）
```

## 关键边界

YOLO26 只产生视觉候选证据，不直接判定“合规/违规”。风险结论还必须考虑地点、区域、图片质量、知识依据和不确定性。任何低质量、未检出、低置信度、知识不足、LLM 失败或工具失败都会如实记录并转入人工复核，不以模拟结果掩盖失败。

模型对象在后端进程内延迟单例加载；任务间复用，避免每次请求重复加载。数据库会保存任务、图片元数据、检测框、Agent 运行与步骤、风险结果、报告、人工复核和反馈。

## 环境策略

- 测试：SQLite 临时库、Qdrant 内存模式、假的可控 YOLO 工具。
- 本地开发：SQLite + Qdrant 嵌入式模式，可连接本机 GPU 权重。
- 生产：MySQL + Qdrant 服务 + Nginx；模型文件只读挂载。
