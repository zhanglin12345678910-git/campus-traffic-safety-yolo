# RAG 设计

## 入库

知识库支持 PDF、DOCX、TXT 和 Markdown。文件经白名单、大小和安全文件名检查后存储，提取正文并按约 500 字、80 字重叠分块；每个片段写入文档 ID、文档名、片段 ID 与正文。

## 向量

默认 `hash` 提供者使用可重复的中文字符 n-gram 哈希向量，完全离线，适合开发与测试。它不等同于语义嵌入模型。生产可将 `EMBEDDING_PROVIDER` 设为 `openai_compatible`，配置兼容 `/embeddings` 接口的地址、密钥和模型。

## 检索与引用

查询由区域、地点、YOLO 类别和“校园交通安全巡检”组成。Qdrant 使用余弦距离返回 Top-K，并执行分数阈值过滤。风险结果仅引用真实返回的文档名、片段 ID、正文和分数；没有命中时明确标记“知识依据不足”并转人工复核。

## 资料治理

仓库内示例规范只用于开发与测试，已明确标注不是正式法规。部署前应导入学校审核的制度、台账和处置流程，并记录版本、适用范围和生效时间。不得让未经审核的材料自动形成行政或法律结论。
