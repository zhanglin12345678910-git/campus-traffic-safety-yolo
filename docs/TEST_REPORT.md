# 测试说明

## 自动化测试

在安装开发依赖后执行：

```bash
cd backend
python -m pytest
```

后端测试覆盖接口、数据持久化、输入校验、图片质量、风险策略、人工复核、报告、视频规则、服务异常和容器配置契约。测试使用临时数据与替代服务，不访问正式数据库。

部分测试使用模拟检测和外部接口，因此通过测试不能证明真实权重、外部服务连通性或部署环境性能。

## 前端检查

```bash
cd frontend
npm ci
npm run typecheck
npm run build
```

`frontend/scripts/` 提供界面与端到端检查脚本，执行前应按脚本要求启动服务并准备隔离测试环境。测试创建的任务与素材不作为正式巡检档案。

## 实际运行验证

- 检查两类检测权重路径、设备配置和真实推理结果。
- 使用授权素材验证图片质量、检测框、知识引用、报告和人工复核。
- 视频单独验证连续轨迹、方向配置、事件时段和处理耗时。
- 配置外部服务后分别验证调用成功与异常回退。
- 确认页面展示真实任务和健康状态，不将未加载状态当作已推理。
- 记录设备、模型校验值、资料版本、样本规模和失败情况。

现场测试使用 [验证记录模板](REAL_WORLD_VALIDATION_TEMPLATE.md)。准确率与耗时只引用对应环境的实测结果，不将小样本检查或目标值写成通用结论。
