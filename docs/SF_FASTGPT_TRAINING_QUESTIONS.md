## 六、培训后行动计划

根据培训确认的结果，下一步可能需要：

| 场景 | 需要做的事 |
|------|-----------|
| 平台需要公网地址 | 配置内网穿透（ngrok/cpolar）或部署到云服务器 |
| 平台不支持 multipart | API 增加 Base64 JSON 上传方式 |
| 平台不支持 Header 鉴权 | API 增加 Query 参数鉴权方式 |
| 平台需要 HTTPS | 配置 SSL 证书或使用反向代理 |
| 平台需要 OpenAPI 导入 | 已有 `docs/openapi.json`，可直接使用 |
| 需要 API 返回纯文本摘要 | API 增加 `summary` 文本字段 |
| 首次加载超时 | 预热模型或增加启动脚本 |
