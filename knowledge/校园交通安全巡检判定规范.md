# 校园交通安全巡检判定与整改规范

本规范用于统一「区域类型 + 视觉检测结果 + 现场描述」到「风险等级 + 整改建议」的判定口径，
适用于安巡智脑（校园交通安全巡检 AI 数字员工）的自动研判与人工复核。

系统在检索时使用的查询词形式为：**区域类型 + 地点 + 检出类别 + 校园交通安全巡检**。
因此本规范按区域类型分节编写，每节均包含该区域的关键词、典型风险、判定要点与整改要求。

**阅读说明**：本文件按约 500 字分块入库，一个知识片段可能同时包含相邻两节的内容，
章节标题与正文存在错位可能。因此**每条判定要点均自带区域名称**（如「校门口」「宿舍区」），
请以条文中标注的区域为准，不要依据片段中的章节标题归属风险。

适用范围：校门口、停车场、校园主干道、宿舍区、食堂周边、教学楼路口、消防通道，以及其他校园区域。

## 一、通用判定规则

**风险等级口径**：

- low（低风险）：现场要素正常，未发现违规占用、人车冲突或标志缺失；仅需按周期例行复查。
- medium（中风险）：存在违规行为或设施缺陷，但尚未直接危及人身安全，例如车辆越线停放、标志被遮挡、减速设施磨损；需限期整改并记录台账。
- high（高风险）：存在直接危及人身安全的情形，例如消防车通道被占用堵塞、人车混行且无隔离、车辆逆行、超速通过人员密集区；需立即处置并上报。
- review（待复核）：证据不足、置信度偏低、模型不可用或信息缺失时，不给出确定性结论，转人工复核。

**通用判定纪律**：

1. 不得仅凭单张静态图片断言「标志缺失」，只能表述为「该视角未检出」，需结合点位应有标志台账复核。
2. 低置信度检测只能作为线索，不得写成确定事实。
3. 涉及人员聚集的结论，应结合视频持续时间与区域边界确认，静态图片不足以定性。
4. 不得引用知识片段以外的法规编号；引用法规时必须标注法规名称与条款号。
5. 逆行属时序行为，单张静态图片无法确认行驶方向。图片巡检检出 pne（禁止驶入）、
   p5（禁止掉头）、i5（靠右侧道路行驶）等标志时，只能作为「该点位存在逆行风险
   关注点」的线索；确定性逆行判定需视频轨迹或现场复核，机动车、非机动车依法
   实行右侧通行（《中华人民共和国道路交通安全法》第三十五条）。

**通用整改闭环**：发现 → 登记台账 → 明确责任部门 → 限期整改 → 复查确认 → 归档。

## 二、校门口（校门出入口）

**检索关键词**：校门口 校门 出入口 东门 南门 北门 人车混行 人员聚集 校园交通安全巡检

**典型风险**：上下学与就餐高峰人车混行；车辆在门口随意停靠上下客；非机动车逆行、乱穿；
门口减速设施或警示标志不清晰；外来车辆未登记驶入。

**判定要点**：

1. 校门口检出车行道内出现 person 与 car、bus、motorcycle 同框，且无隔离设施，判为人车混行风险。
2. 校门口检出车辆停放在校门通道、斑马线或网格线区域内，判为违规停靠占道。
3. 校门口检出 bicycle、motorcycle 等非机动车行驶方向与地面导向箭头或 i5（靠右侧道路行驶）
   标志相反，提示存在逆行线索；单帧静态图片无法确认行驶方向，需视频轨迹或现场复核确认。
   校门口检出 pne（禁止驶入）标志，说明该点位禁止车辆驶入，驶入即违反禁令标志，属逆行风险关注点。
4. 校门口检出 ip（人行横道）、w57（注意行人）、w55（注意儿童）标志，说明该点位已有行人警示设置，
 应核查标志是否被遮挡、是否与地面标线冲突，而不是重复增设。

**整改要求**：校门口高峰时段实行人车分时放行或增设物理隔离；校门通道划定禁停区并设置隔离柱；
外来车辆实行登记与限速准入；补齐校门口减速带与限速标志。

## 三、停车场（含路边停车区）

**检索关键词**：停车场 路边停车区 停车位 车辆停放 违停 消防通道 校园交通安全巡检

**典型风险**：一车占两位、越线停放；占用消防车通道或人行通道停车；占用非机动车与无障碍车位；
停车区出口视线遮挡；电动自行车违规拉线充电。

**判定要点**：

1. 停车场检出 car、bus、truck、motorcycle 的检测框明显跨越车位标线，判为越线或跨位停放。
2. 停车场检出车辆停放在消防车通道黄网格区域内，判为占用消防车通道，直接按高风险处置。
3. 停车场检出 pn（禁止停车）、pne（禁止驶入）标志区域内有车辆长期停放，判为违反禁令标志。
4. 停车场检出 person 集中在车辆周边而无正常通行路径，需结合现场判断是否存在骑行、装卸或聚集行为。

**整改要求**：停车场补划并复新车位标线；在消防车通道两端加设「禁止占用」警示与硬隔离；
建立违停登记与通知挪车机制；停车场出入口加装广角镜或反光标识。

**法定依据**：《中华人民共和国消防法》第二十八条；《企业事业单位内部治安保卫条例》第十一条。

## 四、消防通道（消防车通道、疏散通道）

**检索关键词**：消防通道 消防车通道 疏散通道 安全出口 占用 堵塞 停车 校园交通安全巡检

**典型风险**：机动车、电动自行车、货物、垃圾箱占用或堵塞消防车通道；安全出口被锁闭或堆放杂物；
常闭式防火门处于开启状态；疏散指示标志与应急照明缺失。

**判定要点**：

1. 消防通道检出任何 car、truck、bus、motorcycle 停放在消防车通道范围内，不论停放时长，
 一律判为高风险并须即时处置。
2. 消防通道检出宿舍区、食堂、教学楼周边的疏散通道被车辆或杂物阻断，判为占用疏散通道。
3. 消防通道检出通道两侧停放车辆导致有效通行宽度明显收窄，判为妨碍消防车通行。
4. 本类隐患属法定禁止行为，任何区域都不得以「临时停放」「不影响通行」为由降低风险等级。

**整改要求**：立即移除占道车辆与杂物；在通道地面施划黄色网格禁停线并设置警示牌；
将消防车通道畅通纳入每日防火巡查，保留巡查记录；对反复占用的点位加装硬质隔离或监控抓拍。

**法定依据**：《中华人民共和国消防法》第二十八条；《高等学校消防安全管理规定》第十六条、第二十九条、第三十条。

## 五、宿舍区

**检索关键词**：宿舍区 学生宿舍 宿舍楼 疏散通道 人员聚集 电动自行车 充电 校园交通安全巡检

**典型风险**：宿舍区道路车辆超速行驶；楼栋出入口人员聚集阻碍通行；
电动自行车乱停乱放、堵塞疏散通道；拉线充电、楼道充电；夜间照明不足导致行人风险。

**判定要点**：

1. 宿舍区检出 person 密集聚集在宿舍楼出入口、楼道口或宿舍区主路，人数达到聚集阈值（默认 8 人），
 判为人员聚集阻碍通行；如聚集位置占用疏散通道，按高风险处置。
2. 宿舍区检出 car、bicycle、motorcycle 在宿舍区主路密集通行且限速标志（pl5、pl20）不明显，
 判为超速风险线索。
3. 宿舍区检出 bicycle、motorcycle 停放在宿舍楼门前、楼道口或疏散通道内，判为占用疏散通道与违规停放。
4. 学生宿舍属于消防安全重点部位，须加强夜间防火巡查。

**整改要求**：宿舍区实行限速与单向通行；设置集中充电棚并禁止楼道充电与飞线充电；
楼下划线规范非机动车停放；在楼栋出入口设置排队引导与隔离带；补齐夜间照明与减速设施。

**法定依据**：《高等学校消防安全管理规定》第十三条、第十四条、第二十九条。

## 六、校园主干道（含人车混行道路、减速带路段）

**检索关键词**：校园主干道 人车混行 减速带 限速 逆行 超速 校园交通安全巡检

**典型风险**：机动车超速；人车混行无隔离；车辆逆行或违规掉头；减速带破损、缺失或反光标识失效；
禁鸣标志路段鸣笛扰民；行人在车行道内行走。

**判定要点**：

1. 校园主干道检出 person 与 car、bicycle、motorcycle 同框通行，且无物理隔离或标线分隔，判为混行风险。
2. 校园主干道检出 pl5、pl20、pl30、pl40 等限速标志，而该路段减速带破损或反光标识失效，
 判为减速设施缺陷。
3. 校园主干道检出 p11（禁止鸣喇叭）标志，说明该点位为禁鸣区；
 若同帧检出车辆密集通行，应核查是否存在鸣笛扰民问题。
4. 校园主干道检出 p5（禁止掉头）、p23（禁止向左转弯）、p19（禁止向右转弯）标志，
 而现场存在对应转向行为线索，判为违反禁令标志。
5. 校园主干道检出 car、motorcycle 行驶方向与地面导向箭头、单行标志或 pne（禁止驶入）、
   p5（禁止掉头）标志相反，提示存在逆行线索；机动车、非机动车实行右侧通行，
   单帧静态图片无法确认行驶方向，视频轨迹确认后按高风险处置。

**整改要求**：校园主干道实行限速并加装测速或减速设施；人车密集路段增设护栏实现物理隔离；
复新破损减速带与反光标识；在急弯、路口、宿舍区路段增设警告标志。

## 七、食堂周边（人员密集场所）

**检索关键词**：食堂周边 食堂 人员密集 人员聚集 排队 外卖 校园交通安全巡检

**典型风险**：就餐高峰人员聚集至道路；外卖与非机动车临时停放占道；后勤货运车辆在就餐时段通行；
通道被餐车、货物占用。

**判定要点**：

1. 食堂周边检出 person 数量达到聚集阈值（默认 8 人），触发人员聚集事件；
 判定需结合视频持续时长与区域边界确认。
2. 食堂周边检出 motorcycle、bicycle 集中在食堂门口道路，判为非机动车临时停放占道。
3. 食堂周边检出 truck 在就餐高峰时段于人员密集区通行，判为货运时段安排不合理。
4. 食堂周边属人员密集场所，门窗不得设置影响逃生和灭火救援的障碍物。

**整改要求**：食堂周边错峰就餐或设置排队引导区；划定外卖与非机动车临时停放区；
后勤货运调整为非就餐时段；保持食堂周边消防通道与安全出口畅通。

**法定依据**：《中华人民共和国消防法》第二十八条；《高等学校消防安全管理规定》第十四条。

## 八、教学楼路口（教学楼及公共教室周边）

**检索关键词**：教学楼路口 教学楼 实验楼 图书馆 路口 视距 校园交通安全巡检

**典型风险**：课间人流与车流在路口交汇；路口视距不良、缺少减速让行或警示标志；
车辆在楼前违规停放；夜间自习后照明与警示不足。

**判定要点**：

1. 教学楼路口检出 pg（减速让行）、w13（十字交叉路口）、w59（注意合流）标志，
 说明该路口已有让行或警示设置，应核查标志是否被树枝、广告牌、车辆遮挡。
2. 教学楼路口检出 person 与 car 交叉通行且无信号灯或减速设施，判为混行冲突风险。
3. 教学楼路口检出车辆停放在教学楼门前消防通道或疏散通道上，按占用消防通道高风险处置。

**整改要求**：教学楼路口课间高峰安排引导或实行车辆绕行；路口增设减速让行与注意行人标志；
清理遮挡标志的树枝与广告牌；楼前划定禁停区。

## 九、电动自行车与非机动车专项（含共享单车、外卖配送）

**检索关键词**：电动自行车 非机动车 共享单车 外卖 快递 配送 骑行 逆行 载人 bicycle motorcycle 校园交通安全巡检

**判定要点**：

1. 检出 i2（非机动车行驶）、i4（机动车行驶）、i5（靠右侧道路行驶）等指示标志，
   说明该路段已明确通行规则，应对照核查实际通行方向是否与标志一致。
2. 检出非机动车驶入明确标注为机动车通行或禁止非机动车进入（p6）的道路，判为违反指示或禁令标志。
3. 检出电动自行车在人员密集区、宿舍区快速穿行，或违规载人载物，判为中高风险。
4. 电动自行车在非机动车道内行驶时，最高时速不得超过十五公里。
5. 校门口、食堂周边、教学楼路口检出 bicycle（含共享单车）成排倒放、堆叠，
   或停放在道路、绿化带、疏散通道、消防车通道内，判为共享单车乱停放占道；
   占用消防车通道的按高风险处置。
6. 食堂周边、宿舍区检出 motorcycle（含外卖、快递配送车辆）在人员密集区快速穿行、
   违规载人载物，或在门口道路临时停放占道，判为配送车辆违规穿行与占道。

**整改要求**：规范非机动车停放与充电；在混行路段设置非机动车道或推行区；
对违规骑行开展宣传教育与劝导；设置限速与减速设施；共享单车实行定点停放与
定量投放，投放企业与学校共同清理违规停放车辆；外卖、快递配送车辆实行
校园准入登记与限定时段、限定路线通行，在食堂周边划定配送车辆临时停放区。

**法定依据**：《中华人民共和国道路交通安全法》第五十七条、第五十八条；GB 17761-2024《电动自行车安全技术规范》。

## 十、恶劣天气与不良路况专项

**检索关键词**：恶劣天气 雨天 湿滑 积水 雾 结冰 校园主干道 校门口 停车场 car motorcycle bicycle person 校园交通安全巡检

**判定要点**：

1. 校园主干道、校门口、停车场遇雨、雪、雾、结冰等恶劣天气时，行驶中的 car、
   motorcycle 应当降低行驶速度；遇雾、雨、雪、沙尘、冰雹致能见度在 50 米以内，
   或在冰雪、泥泞路面上行驶时，最高时速不得超过每小时 30 公里。
2. 校门口、校园主干道雨天路面积水湿滑时，人车混行风险应提高一级评估；
   路面标线、减速带、导向箭头被积水或积雪覆盖时，不得断言标线缺失，
   应表述为「被覆盖，天气好转后复核」。
3. 雾天教学楼路口、校园主干道能见度降低，行人与车辆交叉冲突风险上升；
   低能见度下行驶的车辆应开启前照灯、示廓灯和后位灯，雾天应开启雾灯
   和危险报警闪光灯。
4. 雨雪天气宿舍区、食堂周边的电动自行车（bicycle、motorcycle）制动距离变长，
   超速穿行与违规载人的风险应提高一级评估。
5. 天气证据以巡检现场说明中记载的实时天气为准；无天气信息时按常规天气口径评估，
   不得自行假定恶劣天气拔高结论。

**整改要求**：恶劣天气时段在校园主干道、校门口安排减速提示与人员疏导；
雨雪后及时清扫积水、积雪并复检标志标线可视性；雾天在重点路口增设临时警示与照明；
恶劣天气减少或暂停外卖配送车辆驶入人员密集区。

**法定依据**：《中华人民共和国道路交通安全法》第四十二条；《中华人民共和国道路交通安全法实施条例》第四十六条、第五十八条。

## 十一、结论表述与不确定性说明

1. 所有结论必须区分「已确认事实」与「需复核线索」，并在 uncertainty_note 中说明不确定性来源。
2. 图片质量不达标（模糊、过暗、逆光、遮挡）时，不得据此形成确定性结论，应转人工复核。
3. 未检出目标时，只能表述为「本张图片未检出相关目标」，不得表述为「现场不存在该问题」。
4. 涉及人员聚集的结论，应结合监控视频持续时间与区域边界确认，静态图片不足以定性。
