# 模型文件

权重文件单独配置，不提交到 Git。

| 文件 | 用途 |
|---|---|
| `yolo26-tt100k-best.pt` | TT100K 45 类交通标志检测，通过 `YOLO_MODEL_PATH` 配置 |
| `yolo26m.pt` | 通用目标检测，通过 `GENERAL_YOLO_MODEL_PATH` 配置；应用仅采纳人员与车辆白名单 |

交通标志模型与通用模型职责独立，不用通用类别覆盖专用交通标志结果。人员聚集来自目标计数与规则，逆行来自连续视频轨迹与方向配置，不能由单帧图片证明。

## 项目采用的交通标志检查点

- 架构与输入：YOLO26m，640，45 类。
- 数据规模：训练集 28,083 张，验证集 8,016 张，独立测试集 3,992 张。
- 检查点：第 32 个完整 epoch；训练计划未全部完成。
- 验证集：mAP50 0.82615，mAP50-95 0.62980。
- 独立测试集：Precision 0.86560，Recall 0.76376，mAP50 0.83880，mAP50-95 0.64666。
- SHA-256：`0d4ad7756c965bdb5ec2520c7124a195fabc28084cc6039ec02e1aa6a15dd9af`。

以上为该检查点的记录，不代表所有校园场景的准确率。仓库不提供评估原始数据，复现需准备相应授权数据、训练记录与环境。训练及评估脚本见 [训练说明](../training/README.md)。
