# 模型权重目录

当前部署使用两份权重；权重文件不会提交到 Git：

- `yolo26-tt100k-best.pt`：TT100K 45 类交通标志专用模型，可通过 `YOLO_MODEL_PATH` 配置。
- `yolo26m.pt`：当前默认的官方 COCO 80 类通用模型，可通过 `GENERAL_YOLO_MODEL_PATH` 配置；应用只采纳人员、自行车、汽车、摩托车、公交车和货车六类。混合来源样本按 SHA-256 去重后的 10 张唯一图片中，其检出总数比 nano 约高 34%（35 → 47），但该样本无人工真值，不能据此宣称准确率或召回率提升。
- `yolo26n.pt`：保留的低资源回退模型，不作为当前默认模型。

## 当前权重来源与指标

- 架构：YOLO26m，输入尺寸 640，TT100K 45 类。
- 数据：完整训练集 28,083 张、验证集 8,016 张；`fraction=1.0`。
- 选择：原计划 80 epochs，按用户要求在第 33 轮中途停止；使用第 32 个完整 epoch 的 `best.pt`。该轮也是所有已完成轮次中验证集 mAP50-95 最高的一轮。
- 第 32 轮验证集：mAP50 0.82615，mAP50-95 0.62980。
- 独立 test 集 3,992 张：Precision 0.86560、Recall 0.76376、mAP50 0.83880、mAP50-95 0.64666。
- 文件大小：131,630,898 bytes。
- SHA-256：`0d4ad7756c965bdb5ec2520c7124a195fabc28084cc6039ec02e1aa6a15dd9af`。

详细的可核验路径、测试命令和运行态结果见 `docs/TEST_REPORT.md`。

通用模型用于人员/车辆检测、人数阈值和 ByteTrack 视频跟踪。人员聚集由目标计数与阈值规则产生，逆行由连续轨迹与道路允许方向产生；二者都不是交通标志模型的新类别，也不把单帧图片当作逆行证据。

旧项目中的兼容基线权重：

`runs/train/TT100K-增强-yolo11-第一个实验-newt100k2/weights/best.pt`

该权重为 45 类 TT100K YOLO11 自定义模型，只用于旧结果对照，不能作为最终 YOLO26 成果。新项目训练完成后使用 `yolo26-tt100k-best.pt`。
