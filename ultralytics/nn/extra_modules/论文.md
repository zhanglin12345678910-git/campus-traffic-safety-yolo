知识蒸馏策略与改进点
知识蒸馏通常包含硬标签（hard labels）与软标签（soft labels）两类监督信号。硬标签来源于真实标注，用于保证模型学习真实数据分布；软标签由教师模型输出的类别概率分布提供，可反映类别间相似关系。其通用形式为：
L_total = αL_hard + βL_soft
在目标检测任务中，本文将硬标签损失统一表示为检测损失 L_det，因此最终优化目标为：
L_total = L_det + β · L_kd
检测任务包含分类、边界框回归与目标置信度等多个分支。若对全部分支同时蒸馏，容易引入背景噪声并导致训练不稳定。因此，本文采用输出层分类分支 Logits 蒸馏策略，仅对检测头分类分支施加蒸馏约束。
具体过程如下：
1）学生模型前向传播并计算检测损失 L_det；
2）冻结教师模型，对同一输入进行前向推理；
3）提取教师与学生分类 logits，并进行温度缩放；
4）通过 KL 散度计算蒸馏损失 L_kd，并与检测损失联合优化。
蒸馏计算如下：
p_t = softmax(z_t / T)
p_s = softmax(z_s / T)
L_kd = T² · KL(p_t || p_s)
其中 z_t 与 z_s 分别为教师模型与学生模型分类分支输出，T 为蒸馏温度。

4.2.1  P5检测层裁剪
在实际道路场景中，交通标志目标通常以中小尺度甚至微小尺度形式出现，而 YOLO 系列原始检测框架中的 P5 检测层主要面向大尺度目标，其输出特征图经过 32 倍下采样，空间分辨率较低。对于交通标志检测任务而言，P5 检测层在目标尺度匹配上存在一定冗余，其对小目标检测的贡献相对有限，却会引入额外的参数量和计算开销。尤其在车载边缘设备等资源受限平台上，该分支所带来的冗余计算将进一步增加模型部署负担，不利于模型的轻量化设计与实时应用。
基于交通标志目标的尺度分布特点，本文对原模型的检测层级结构进行了针对性精简，移除了 Neck 中对应大尺度目标检测的 P5 分支，仅保留更适合中小目标检测的 P2、P3 和 P4 三个检测层。其中，P2 检测层用于保留浅层高分辨率特征，增强模型对极小目标的感知能力；P3 和 P4 检测层则分别承担小目标与中等尺度目标的检测任务。通过裁剪 P5 检测层，模型在保持 Backbone 深层语义特征提取能力的同时，减少了不必要的特征融合与预测计算，使计算资源能够更加集中于交通标志目标的有效表征与检测。
综上，P5 检测层裁剪在不改变网络整体主干特征提取能力的前提下，降低了模型的参数量与计算复杂度，使网络结构更加符合交通标志检测任务的目标尺度分布特征，也为后续 Slim-Neck 轻量化设计与 SC-Head 共享检测头的构建奠定了基础。
4.2.2  Slim-Neck
在 YOLO11 检测框架中，原始 Neck 采用标准卷积与 C2f/CSP 结构构建自顶向下和自底向上的多尺度特征融合路径，能够较好地整合不同层级的语义信息与空间信息，从而提升模型对多尺度目标的检测能力。然而，在轻量化交通标志检测场景下，原始 Neck 在高分辨率特征层上的卷积堆叠与通道配置仍然带来了较高的参数量与计算开销。尤其是在 P2、P3 等浅层特征图经过多次上采样、拼接与卷积融合后，特征通道冗余较为明显，导致 FLOPs 显著增加，不利于模型在车载边缘设备等资源受限平台上的实时部署。
针对上述问题，本文在保持原有自顶向下与自底向上特征流向基本不变、以及多尺度特征融合拓扑结构基本不变的前提下，对 Neck 部分进行了轻量化重构，引入 Slim-Neck 结构。具体而言，本文将原 Neck 中的部分标准卷积和 C2f 模块分别替换为 GSConv 与 VoVGSCSP，从而在尽可能保持特征融合能力的基础上，降低 Neck 部分的参数量与计算复杂度，实现轻量化设计。
其中，GSConv 是一种兼顾特征表达能力与计算效率的轻量化卷积结构。该模块结合了标准卷积、深度可分离卷积以及通道混洗操作，其中标准卷积用于保留较强的局部特征提取能力，深度可分离卷积用于降低计算量，而通道混洗则用于增强不同通道之间的信息交互。通过这种方式，GSConv 能够在接近普通卷积特征提取效果的前提下，有效减少参数量与计算开销，因此更适用于轻量化检测模型中的特征融合阶段。GSConv 的具体结构如图 4-x 所示。

4.2.2  SC-Head共享检测头
在目标检测任务中，检测头承担类别预测与边界框回归两项核心功能，其结构设计直接影响模型的检测精度、参数规模与推理效率。传统解耦检测头通常在不同尺度特征层上分别构建独立的分类分支与回归分支，即针对 P2、P3、P4 等多尺度特征图分别设置对应的卷积预测模块，各尺度之间参数互不共享。该结构能够增强不同尺度特征的独立建模能力，但同时引入了较大的参数冗余。随着检测尺度数量增加，检测头的参数量与计算量同步增长，不利于模型在资源受限场景下的轻量化部署，尤其限制了其在车载终端与边缘设备中的实时应用。
为降低多尺度检测头中的重复参数开销，以 RetinaNet[1] 和 FCOS[2] 为代表的经典单阶段目标检测方法引入了跨尺度共享检测头的设计思想。这类方法通过在特征金字塔不同尺度层之间复用分类与回归子网络的卷积参数，有效减少了检测头内部的结构冗余，并提升了整体推理效率。借鉴这一设计思想，并结合交通标志检测任务中小目标占比较高、尺度变化显著以及车载部署环境受限等特点，本文对 YOLO11 原生解耦检测头进行了轻量化重构，构建了适用于本任务的共享卷积检测头（Shared Convolution Head, SC-Head）。该结构在检测头前端设置跨尺度共享的卷积特征变换模块，对来自 P2、P3 和 P4 的多尺度特征图进行统一映射，在保持分类与回归解耦预测优势的同时，显著降低了多尺度检测分支中的参数冗余与计算开销。SC-Head 的整体结构图如下所示

图6给出了 SC-Head 的整体结构。输入的多尺度特征图 P2、P3 和 P4 首先分别经过一个 3×3 卷积层完成初步特征调整，随后进入共享卷积特征提取模块。该模块由一层 3×3 深度卷积和一层 1×1 逐点卷积串联构成，其中深度卷积的 groups 设置为输入通道数，用于在低计算开销下提取各通道的空间局部信息，逐点卷积则用于完成通道间的信息融合与特征重组。通过该共享模块，不同尺度特征图在统一参数约束下完成特征变换，从而实现跨尺度卷积权重共享。
与原始 YOLO11 检测头相比，SC-Head 对检测头中的卷积组织方式进行了轻量化重构。原始检测头在不同尺度分支中分别维护独立的卷积参数，且分类分支与回归分支的卷积结构并不一致。其中，分类分支采用基于深度卷积与逐点卷积的轻量化卷积结构，而边界框回归分支仍主要采用标准卷积。该设计能够分别满足分类与定位任务的预测需求，但在多尺度预测场景下，不同尺度分支重复堆叠卷积操作，容易带来较大的参数冗余与计算开销。针对这一问题，本文在各尺度特征初步调整之后，引入跨尺度共享的特征提取模块，并采用深度卷积与逐点卷积组合对多尺度特征进行统一变换，从而减少不同尺度检测头之间的重复卷积计算，提高检测头的参数利用效率。在共享特征提取完成后，SC-Head 仍采用分类分支与回归分支相互解耦的预测方式。共享卷积模块输出的特征图分别送入轻量化分类预测分支和边界框回归分支，以完成类别概率估计与目标位置回归。该设计在实现跨尺度参数共享的同时，保留了解耦检测头在任务建模上的优势，有助于减弱分类任务与定位任务之间的优化冲突，从而维持检测头对类别判别与边界框回归的表达能力。
考虑到不同尺度特征层对应的目标尺寸分布存在差异，统一共享卷积参数虽然能够有效压缩模型规模，但也可能削弱检测头对尺度变化的适应能力。尤其在交通标志检测任务中，P2 特征层更侧重于小目标响应，而 P4 特征层更多承担中大目标的定位任务，不同尺度特征在语义强度与空间分辨率上存在明显差异。为缓解不同特征层在边界框回归范围上的尺度不匹配问题，本文引入 FCOS 【20】中的可学习尺度调节思想，在回归分支末端设置独立的尺度缩放层（Scale Layer），以实现对各检测层回归输出的自适应校准。
综上所述，SC-Head 在检测头前端引入了跨尺度共享的卷积特征提取模块，并在后续预测阶段保留了分类分支与回归分支相互解耦的结构形式，同时结合尺度缩放校准策略，对原始检测头进行了轻量化改造。该结构通过共享不同尺度检测分支中的部分卷积参数，减少了检测头内部重复的特征变换过程，从而有效降低了参数冗余与计算开销。与此同时，分类与回归分支的解耦设计保证了两类任务能够分别完成预测，尺度缩放层则进一步提升了检测头对不同尺度目标的适应能力。因此，SC-Head 在降低模型复杂度的同时，仍能够保持对不同尺度交通标志目标的检测性能，更适用于复杂道路场景下的实时检测任务。  接下来我该如何写呢  需要画什么图或者写啥公式呢
