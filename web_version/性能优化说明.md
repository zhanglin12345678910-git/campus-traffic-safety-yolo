## 📊 性能对比分析

### 桌面版 (app.py) vs 网页版性能差异

| 方面 | 桌面版 (app.py) | 原网页版 | 优化后网页版 |
|------|----------------|----------|-------------|
| **摄像头处理** | 多线程持续连接 | HTTP轮询 | WebSocket + 多线程 |

| **CPU使用率** | 中等 | 高 | 中等 |

## 🔧 主要优化措施

### 1. 摄像头处理优化
```python
# 原版本：每次请求重新打开摄像头
cap = cv2.VideoCapture(0)  # 每次都重新初始化
ret, frame = cap.read()
cap.release()  # 立即释放

# 优化版本：持续连接 + 多线程处理
class OptimizedCameraProcessor:
    def __init__(self):
        self.cap = cv2.VideoCapture(0)  # 持续连接
        self.thread = threading.Thread(target=self._process_loop)
```

### 2. 检测参数优化
```python
# 原版本
results = model.predict(frame, imgsz=640, conf=0.3, iou=0.5)

# 优化版本
results = model.predict(
    frame, 
    imgsz=416,    # 降低分辨率提升速度
    conf=0.4,     # 提高置信度阈值减少误检
    iou=0.6,      # 提高IoU阈值减少重复框
    half=True     # GPU时使用半精度加速
)
```

### 3. 图像传输优化
```python
# 原版本：高质量编码
_, buffer = cv2.imencode('.jpg', vis)

# 优化版本：压缩优化
# 1. 调整图像大小
if width > 480:
    vis = cv2.resize(vis, (480, new_height))

# 2. 高压缩率编码
encode_params = [cv2.IMWRITE_JPEG_QUALITY, 60]
_, buffer = cv2.imencode('.jpg', vis, encode_params)
```

### 4. 通信协议优化
```javascript
// 原版本：HTTP轮询
setInterval(() => {
    fetch('/api/camera/frame')  // HTTP请求开销大
}, 50);

// 优化版本：WebSocket实时通信
socket.on('camera_result', (data) => {
    // 实时接收，无轮询开销
    updateDisplay(data);
});
```
