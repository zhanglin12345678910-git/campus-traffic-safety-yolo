# 🎯 多模型配置说明

## 📋 已配置的检测模型

本Web系统已配置以下11个知名目标检测模型，供您随时切换使用：

### 🏆 自研改进模型

#### PSSM-YOLO（默认）
- **全名**: Position-Sensitive Spatial Modulation YOLO
- **特点**: 基于YOLO11改进的自研模型，采用PMSFA注意力机制和CSP结构
- **优势**: 在交通标志检测上达到最佳精度与速度平衡
- **适用场景**: 生产环境、高精度要求场景

---

### ⚡ YOLO系列轻量模型

#### YOLOv11n
- **发布**: 2023年（YOLO最新版本）
- **特点**: 超轻量级，参数量极小
- **优势**: 速度极快，适合边缘设备
- **适用场景**: 实时检测、移动端部署

#### YOLOv10n
- **发布**: 2024年
- **特点**: 端到端检测，无需NMS后处理
- **优势**: 推理延迟低，精度高
- **适用场景**: 实时应用、低延迟需求

#### YOLOv9t
- **发布**: 2024年初
- **特点**: 可编程梯度信息(PGI) + GELAN架构
- **优势**: 精度和速度兼顾
- **适用场景**: 通用检测任务

#### YOLOv8n
- **发布**: 2023年（Ultralytics官方）
- **特点**: 训练友好、生态完善
- **优势**: 工业界最受欢迎，社区支持丰富
- **适用场景**: 快速原型开发、生产环境

#### YOLOv7-tiny
- **发布**: 2022年
- **特点**: 多种训练技巧优化
- **优势**: 紧凑高效
- **适用场景**: 资源受限场景

#### YOLOv5n
- **发布**: 2020年
- **特点**: 成熟稳定，文档丰富
- **优势**: 社区支持最强，部署简单
- **适用场景**: 稳定性优先的项目

## 🔧 模型切换方法

### 方法1: Web界面切换（推荐）
1. 进入"检测"页面
2. 在顶部"选择模型"下拉框中选择目标模型
3. 系统自动切换并显示模型描述

### 方法2: API切换
```bash
# POST 请求切换模型
curl -X POST http://localhost:5000/api/models/active \
  -H "Content-Type: application/json" \
  -d '{"model_id": "YOLOv8n"}'
```

### 方法3: 修改代码默认模型
编辑 `web_app.py` 第83行：
```python
DEFAULT_MODEL_ID = "PSSM-YOLO"  # 改成你想要的默认模型
```

## ⚙️ 自定义添加模型

### 步骤1: 准备模型权重
确保你的 `.pt` 模型文件路径正确

### 步骤2: 修改配置
编辑 `web_app.py` 第65-76行：
```python
MODELS = {
    # 添加你的新模型
    "我的模型": r"<LOCAL_PATH>",
    
    # 保留原有模型...
    "PSSM-YOLO": r"...\best.pt",
}
```

### 步骤3: 更新前端显示（可选）
编辑 `static/js/app.js` 第32-43行：
```javascript
const MODEL_DISPLAY_NAMES = {
    '我的模型': '🌟 我的模型 (自定义)',
    // ...
};

const MODEL_DESCRIPTIONS = {
    '我的模型': '这是我训练的自定义模型描述',
    // ...
};
```

### 步骤4: 重启服务
```bash
# 停止当前服务 (Ctrl+C)
# 重新启动
python web_app.py
```

## 🛠️ 常见问题

### Q1: 模型切换失败？
**A**: 检查模型文件路径是否正确，文件是否存在

### Q2: 模型加载很慢？
**A**: 首次加载需要时间，后续会自动缓存

### Q3: 想删除某个模型？
**A**: 直接从 `MODELS` 字典中删除对应条目即可

### Q4: 所有模型都指向同一个权重文件？
**A**: 是的，目前配置如此。你可以根据需要替换成不同的权重文件路径
