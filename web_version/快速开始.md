## ⚙️ 修改配置

### 改默认模型
编辑 `web_app.py` 第83行：
```python
DEFAULT_MODEL_ID = "PSSM-YOLO"  # 改成你想要的
```

### 改模型路径
编辑 `web_app.py` 第65-76行：
```python
MODELS = {
    "YOLOv8n": r"你的真实路径\yolov8n.pt",
    # ...
}
```

## ❓ 常见问题

### Q: 模型显示"文件缺失"？
**A**: 修改 `web_app.py` 中的模型路径为真实路径

### Q: 如何添加新模型？
**A**: 在 `MODELS` 字典中添加新条目，然后重启服务

### Q: 模型切换没反应？
**A**: 检查浏览器控制台错误，确保模型文件存在
