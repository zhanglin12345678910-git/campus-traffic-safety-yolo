## 🚀 快速开始

### 方式1: 使用批处理文件 (Windows推荐)
1. 双击 `启动Web版本.bat` 文件
2. 按照提示操作即可

### 方式2: 命令行启动
1. **进入Web版本目录**：
   ```bash
   cd web_version_02
   ```

2. **安装依赖包**：
   ```bash
   # 方式1: 只安装Web特需包(推荐，不影响现有环境)
   pip install -r requirements_web_only.txt
   
   # 方式2: 使用灵活版本要求
   pip install -r requirements_simple.txt
   
   # 方式3: 手动安装Web特需包
   pip install Flask Flask-SQLAlchemy Flask-CORS Werkzeug python-dotenv
   
   # 方式4: 完整安装(可能影响现有包版本)
   pip install -r requirements_web.txt
   ```
   
   **💡 建议**: 如果您的yolo_change环境已经有numpy、opencv-python、Pillow、ultralytics等包，
   推荐使用方式1或方式3，只安装Web框架相关的包。

3. **修改模型路径**：
   编辑 `web_app.py` 文件，找到第11行：
   ```python
   MODEL_PATH = r"<LOCAL_PATH>"  # 修改为您的权重文件路径
   ```

4. **启动应用**：
   ```bash
   # 推荐方式：使用启动脚本(会自动检查环境)
   python start_web.py

   # 或者直接启动
   python web_app.py
   ```

5. **访问应用**：
   打开浏览器访问：
   - 本地访问: http://127.0.0.1:5000
   - 局域网访问: http://你的IP地址:5000

### ⚠️ 重要提醒
**必须在 `web_version` 文件夹内运行启动脚本！**
- ✅ 正确: `cd web_version` 然后 `python start_web.py`
- ❌ 错误: 在项目根目录运行 `python web_version/start_web.py`

## 🎯 主要功能

### 🖼️ 图片检测
1. 点击"检测"页面
2. 拖拽或选择图片文件 (JPG, PNG, BMP等)
3. 点击"开始检测"
4. 查看检测结果和统计信息

### 🎬 视频检测
1. 在"检测"页面选择视频文件 (MP4, AVI, MOV等)
2. 点击"开始检测"
3. 系统会自动处理视频的每一帧
4. 查看视频检测摘要和关键帧结果

1. 在"检测"页面点击"启动摄像头"

3. 实时查看检测结果 (约5FPS)
4. 点击"停止摄像头"结束检测

## 📝 重要提醒

1. **模型路径**: 必须修改 `web_app.py` 中的 `MODEL_PATH` 为您的实际权重文件路径
2. **依赖安装**: 确保安装了 `requirements_web.txt` 中的所有依赖包

4. **文件权限**: 确保程序有读写 `uploads` 和 `results` 文件夹的权限

## ❓ 常见问题

**Q: pip安装依赖时出现编码错误？**
A: 这是中文编码问题，请使用以下解决方案：
```bash
# 解决方案1: 使用简化版依赖文件
pip install -r requirements_simple.txt

# 解决方案2: 手动安装
pip install Flask Flask-SQLAlchemy Flask-CORS opencv-python Pillow numpy ultralytics Werkzeug python-dotenv

# 解决方案3: 设置环境变量后重试
set PYTHONIOENCODING=utf-8
pip install -r requirements_web.txt
```

**Q: pip下载时出现网络超时错误？**
A: 这是网络连接问题，请使用以下解决方案：
```bash
# 解决方案1: 使用国内镜像源(推荐)
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements_web_only.txt

# 解决方案2: 增加超时时间
pip install --timeout 300 --retries 5 -r requirements_web_only.txt

# 解决方案3: 使用批处理文件
双击运行 "手动安装依赖.bat"

# 解决方案4: 配置永久镜像源
双击运行 "配置pip镜像源.bat"
```

**Q: 启动时提示模型文件不存在？**
A: 请修改 `web_app.py` 中的 `MODEL_PATH` 为正确的权重文件路径

**Q: 无法访问网页？**
A: 检查防火墙设置，确保5000端口未被阻止

**Q: 检测速度慢？**
A: 可以在 `config.py` 中调整检测参数，或使用GPU加速

**Q: 提示缺少必要文件？**
A: 确保您在 `web_version` 文件夹内运行命令，不要在项目根目录运行
