## 2026-05-29 更新：交通标志数据集完整分析脚本

新增根目录工具脚本：`analyze_traffic_sign_dataset.py`

该脚本用于对 YOLO 格式交通标志数据集进行 **7 个维度的完整分析**，自动检测 data.yaml、发现 train/val/test 分割，并生成 8 张可视化图表 + CSV 统计表 + JSON 完整报告。

### 七大分析维度

| 维度 | 输出的图表 | 说明 |
|------|----------|------|
| 类别分布 | `*_class_distribution.png` | 每类实例数柱状图 + 不平衡比 |
| 框尺寸 | `*_bbox_size.png` | COCO small/medium/large 饼图 + sqrt(area) 直方图 |
| 宽高比 | `*_aspect_ratio.png` | w/h 分布直方图 + 分类饼图 |
| 每图框数 | `*_boxes_per_image.png` | 分布直方图 + 均值/中位数/P99 |
| 图片分辨率 | `*_resolution.png` | 散点图 + 宽高直方图 |
| 位置热力图 | `*_heatmap.png` | 2D 归一化中心坐标热力图 |
| 语义分组 | `*_group_distribution.png` | 禁令/指示/限速/停车让行/警告 五大类 |

### 输出文件

```text
dataset_analysis_output/
├── train/
│   ├── train_class_distribution.png
│   ├── train_bbox_size.png
│   ├── train_aspect_ratio.png
│   ├── train_boxes_per_image.png
│   ├── train_resolution.png
│   ├── train_heatmap.png
│   ├── train_group_distribution.png
│   └── train_class_stats.csv
└── analysis_report.json
```

### 使用方式

```bash
# 自动检测数据集和 data.yaml
python analyze_traffic_sign_dataset.py

# 指定数据目录
python analyze_traffic_sign_dataset.py --data_dir D:/project_workspace/TT100K/1

# 指定 data.yaml + 自定义输出目录
python analyze_traffic_sign_dataset.py --data_yaml data.yaml --output_dir ./my_analysis
```

脚本会自动检测 `images/train/` + `labels/train/` 结构（也支持 `train/images/` + `train/labels/` 格式），如果找不到 `data.yaml` 则使用默认 TT100K 45 个类名。

## 2026-05-26 更新：results.csv 重新生成 results.png 工具脚本

新增根目录工具脚本：`generate_results_png_from_csv.py`

该脚本用于在**只有训练结果 CSV 文件、但没有保存 results.png 图片**的情况下，调用 Ultralytics 原生绘图函数重新生成训练曲线图。

核心调用方式：

```python
from ultralytics.utils.plotting import plot_results
```

### 文件位置

```text
generate_results_png_from_csv.py
```

### 功能说明

| 功能 | 说明 |
|---|---|
| 单个 CSV 转图片 | 输入一个 `results.csv`，生成对应的 `results.png` |
| 批量 CSV 转图片 | 输入一个文件夹，批量生成多个训练曲线图 |
| 递归搜索 | 支持搜索子文件夹中的 CSV 文件 |
| 代码内配置 | 不需要命令行，在脚本顶部填写路径后直接运行 |
| 原生绘图 | 使用 Ultralytics 自带 `plot_results()`，生成 YOLO 原始风格结果图 |

### 在文件中如何使用

打开 `generate_results_png_from_csv.py`，只需要修改顶部配置区：

```python
INPUT_PATH = r"<LOCAL_PATH>"
OUTPUT_PATH = r""
RECURSIVE = False
```

如果 `OUTPUT_PATH` 留空，生成的图片会保存到 CSV 同目录，文件名为：

```text
results.png
```

如果需要批量处理一个文件夹：

```python
INPUT_PATH = r"<LOCAL_PATH>"
OUTPUT_PATH = r"<LOCAL_PATH>"
RECURSIVE = False
```

如果需要搜索所有子文件夹：

```python
INPUT_PATH = r"<LOCAL_PATH>"
OUTPUT_PATH = r"<LOCAL_PATH>"
RECURSIVE = True
```

适用场景：训练结束后只保留了 `results.csv`，但论文或实验汇报中需要恢复 `results.png` 曲线图。
